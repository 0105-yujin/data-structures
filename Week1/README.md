# Week1: 리스트와 친해지기

## 1. 실습 목표
- Python 리스트의 기본 사용법 익히기
- Google Colab 개발 환경에 익숙해지기
- 데이터를 순서대로 저장한다는 개념 이해하기

## 2. 실습 내용
| 단계 | 내용 | 사용한 기능 |
|---|---|---|
| 1 | 리스트 생성 | `[]`, `len()` |
| 2 | 인덱싱과 슬라이싱 | `fruits[0]`, `fruits[-1]`, `fruits[0:2]` |
| 3 | 요소 추가/삭제 | `append`, `insert`, `remove`, `pop` |
| 4 | 장바구니 미니 실습 | `append`로 3개 추가, `pop`으로 마지막 제거 |
| 5 | 선형 탐색 | `for` 반복문, `break` |

## 3. 코드 설명
- **리스트 생성**: `fruits = ["사과", "바나나", "포도"]`처럼 여러 값을 순서대로 담고, `len()`으로 길이를 확인했습니다.
- **인덱싱/슬라이싱**: 인덱스는 0부터 시작하고, 음수 인덱스(`-1`)는 뒤에서부터 센다는 것을 확인했습니다.
- **추가/삭제**: `append`는 맨 뒤에 추가, `insert(1, "수박")`은 원하는 위치에 삽입, `remove`는 값으로 삭제, `pop`은 맨 마지막 요소를 꺼내서 삭제합니다.
- **장바구니 실습**: `cart`에 라면, 샴푸, 프라이팬을 추가한 뒤 `pop()`으로 마지막 물건(프라이팬)을 제거했습니다.
- **선형 탐색**: 리스트를 처음부터 하나씩 확인하다가 `target`을 찾으면 `break`로 멈추는 방식입니다.

## 4. 시간 복잡도 분석
| 연산 | 시간 복잡도 | 이유 |
|---|---|---|
| 인덱싱 `fruits[0]` | O(1) | 위치를 바로 계산해서 접근 |
| `append`, `pop()` (맨 뒤) | O(1) | 다른 요소를 옮길 필요 없음 |
| `insert`, `remove` | O(n) | 뒤쪽 요소를 한 칸씩 밀거나 당겨야 함 |
| 선형 탐색 | O(n) | 최악의 경우 리스트 전체를 확인 |

리스트가 100만 개로 길어지면 선형 탐색은 최악의 경우 100만 번 비교해야 하므로, 데이터가 많을수록 시간이 오래 걸립니다. 이 부분은 다음 주 Big-O 표기법에서 더 자세히 다룹니다.

## 5. 실행 결과
- 장바구니 실습: `['라면', '샴푸', '프라이팬']` → `['라면', '샴푸']`
- 선형 탐색: `target = 1`일 때 "1을(를) 찾았습니다!" 출력

## 6. 느낀 점
리스트에서 append와 pop은 맨 뒤만 건드리니 빠르지만, insert와 remove는 뒤쪽 요소를 전부 밀거나 당겨야 해서 데이터가 많아지면 느려질 수 있다는 점이 새로웠다. 같은 "추가/삭제"라도 위치에 따라 비용이 다르다는 것을 알게 되었다.
